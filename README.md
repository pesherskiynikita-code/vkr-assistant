# vkr-assistant

Бэкенд на Go для выпускной квалификационной работы: ассистент, который превращает текстовую заявку в карточку на доске Nextcloud Deck.

Пользователь пишет заявку обычным текстом, сервер определяет подходящую доску и предлагает карточку. После подтверждения карточка создаётся в Nextcloud Deck вместе с вложениями.

## Возможности

- Список досок Nextcloud Deck (удалённые доски отфильтровываются).
- Создание карточки в нужной колонке с файлами-вложениями.
- Разбор текста заявки ассистентом: выбор доски и заголовка карточки.
  - `Stub` ищет название доски в тексте (для разработки и тестов).
  - `Ollama` обращается к локальной языковой модели (по умолчанию `qwen2.5:7b`) через API Ollama.

## Структура

```
cmd/server/                    HTTP-сервер, точка входа
internal/config/               загрузка настроек из переменных окружения
internal/integration/          общие типы: доска, карточка, вложение
internal/integration/nextcloud/ клиент Nextcloud Deck API
internal/ai/                   интерфейс Assistant и его реализации (Stub, Ollama)
```

## Запуск

Нужен Go версии из `go.mod`.

1. Создайте в корне проекта файл `.env` (он уже в `.gitignore`):

   ```
   NEXTCLOUD_URL=https://cloud.example.com
   NEXTCLOUD_USER=имя_пользователя
   NEXTCLOUD_APP_PASSWORD=пароль_приложения
   NEXTCLOUD_STACK=принято
   ```

   Пароль приложения создаётся в Nextcloud: Настройки, Безопасность, «Создать пароль приложения». `NEXTCLOUD_STACK` необязателен, по умолчанию `принято`: это название колонки, куда попадают новые карточки.

   Вместо файла можно задать те же переменные окружения напрямую.

2. Запустите сервер:

   ```
   go run ./cmd/server
   ```

   Сервер слушает порт `8080`.

## API

| Метод и путь   | Что делает |
|----------------|------------|
| `GET /health`  | Проверка, что сервер жив. Отвечает `ok`. |
| `GET /boards`  | Список досок в JSON. |
| `POST /cards`  | Создаёт карточку. Форма `multipart/form-data`: `board_id`, `title`, `description`, `files` (можно несколько). Отвечает `201` и созданной карточкой. |
| `POST /assist` | Принимает JSON `{"text": "..."}` и возвращает предложенную команду: `{"action": "create_card", "board_id": "...", "title": "...", "description": "..."}`. Карточку не создаёт. Если доску определить не удалось, отвечает `422`. |

Ошибки Nextcloud или модели возвращаются как `502`, некорректный запрос как `400`.

### Примеры (Windows)

```
curl.exe http://localhost:8080/boards

curl.exe -F board_id=1 -F title="Сломалась касса" -F description="Не печатает чек" -F files=@C:\photo.jpg http://localhost:8080/cards
```

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8080/assist -ContentType "application/json; charset=utf-8" -Body '{"text": "сломалась касса"}'
```
