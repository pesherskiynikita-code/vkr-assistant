# vkr-assistant

> ⚠️ **Проект в разработке.** Это выпускная квалификационная работа, часть функций ещё не готова (см. раздел «Статус»).

Голосовой ассистент для создания заявок в Nextcloud Deck. Пользователь мобильного приложения просто говорит, что ему нужно, например «сломалась касса, не печатает чек», и при желании прикрепляет фото или файл. Приложение само определяет, на какую доску отправить заявку, и создаёт карточку.

## Как это работает

1. **Голос.** Пользователь надиктовывает заявку в мобильном приложении и прикрепляет вложения.
2. **Распознавание речи.** Голос переводится в текст.
3. **ИИ выбирает доску.** Текст и список досок отправляются языковой модели. Модель определяет подходящую доску и составляет короткий заголовок карточки.
4. **Подтверждение.** Пользователь видит, куда уйдёт заявка, и подтверждает или исправляет её.
5. **Карточка.** Сервер создаёт карточку в Nextcloud Deck и прикрепляет к ней вложения.

## Архитектура

- **Мобильное приложение** записывает голос, показывает предложенную доску для подтверждения, отправляет вложения.
- **Сервер на Go** связывает всё вместе: получает текст, спрашивает модель, создаёт карточку.
- **Языковая модель** работает локально через Ollama, поэтому тексты заявок не уходят в облачные сервисы.
- **Nextcloud Deck** хранит доски и карточки.

### Структура кода

```

```

## Запуск сервера

Нужен Go версии из `go.mod`.

1. Создайте в корне проекта файл `.env` (он в `.gitignore`):

   ```
   NEXTCLOUD_URL=https://cloud.example.com
   NEXTCLOUD_USER=имя_пользователя
   NEXTCLOUD_APP_PASSWORD=пароль_приложения
   NEXTCLOUD_STACK=принято
   ```

   Пароль приложения создаётся в Nextcloud: Настройки, Безопасность, «Создать пароль приложения». `NEXTCLOUD_STACK` необязателен, по умолчанию `принято`: это колонка, куда попадают новые карточки.

2. Запустите:

   ```
   go run ./cmd/server
   ```

   Сервер слушает порт `8080`.

## API

| Метод и путь   | Что делает |
|----------------|------------|
| `GET /health`  | Проверка, что сервер работает. Отвечает `ok`. |
| `GET /boards`  | Список досок в JSON. |
| `POST /assist` | Принимает текст заявки `{"text": "..."}` и возвращает, куда её предлагается отправить: `{"action": "create_card", "board_id": "...", "title": "...", "description": "..."}`. Карточку не создаёт. Если доску определить не удалось, отвечает `422`. |
| `POST /cards`  | Создаёт карточку после подтверждения. Форма `multipart/form-data`: `board_id`, `title`, `description`, `files` (можно несколько). Отвечает `201` и созданной карточкой. |

Ошибки Nextcloud или модели возвращаются как `502`, некорректный запрос как `400`.
